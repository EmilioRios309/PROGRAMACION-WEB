Conceptos Principales HTML

HTML

Es un Lenguaje de Marcado de Hipertexto es un lenguaje de marca que estructura una pagina web

Elemento HTML

Un elemento HTML es la unidad basica de estructura y contenido en una pagina web, y esta compuesta de:

  • Etiquetas de apertura
  • Atributos
  • Contenido
  • Etiqueta de Cierre

Etiqueta <Head>

Es una etiqueta de metadatos que permite mejorar el SEO , a demas se enlazan archivos externos de estilos o scripts

Etiqueta <body>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra pagina web

Contenedores semanticos

Etiqueta <body> Puede contener tabla el menu principal , el nombre de la empresa, etc.
Etiqueta <nav> Etiqueta utilizada para el menu de navegacion principal y suele contener enlaces a otras paginas relacionadas o navegar por la pagina principal, no debe haber mas de una en la pagina
Etiqueta <main> Etiqueta unica de una pagina web, cuyo proposito es resaltar nuetsro objetivo o mensaje principal de nuestro sitio web, dentro se colocara el contenido principal de la pagina
Etiqueta <Section> Es una etiqueta que poco a poco se intenta que sustituya a DIV su uso es para dividir a una pagina web en secciones y agrupar contenido relacionado
Etiqueta <ARTICLE> Es una etiqueta que se utiliza para agrupar contenido autonomo que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
Etiqueta <footer> Es una etiqueta que norlmante esta al final de una pagina y funciona como cierre del sitio web , a menudo tiene contactos, derecho de autor u otra informacion
Etiqueta <Aside> Esta etiqueta representa una seccion de la pagina web cuyo contenido no esta directamente relacionado con el contenido principal del documento como barras laterales publicidad y enlaces a otros articulos relacionado, etc..

Elementos principales de HTML

Elemento <A>

Este elemento contiene enlaces oara navegar a otras paginas

  • Externos
  • Internos
  • De ancla

Algunos valores especiales que tiene en su atributo href son:

Href="https://wu.me/1234567891"
Este valor envia un wasao a un numero especificado
href="mailto:example@gmail.com"
Enviaba un correo a un mail espefico

Elemento <form>

Es la manera en la que los usuarios se pueden communicar con una pagina web, gracias a este elemento se puede procesar datos de los usarios segun el objetivo de nuestra pagina
